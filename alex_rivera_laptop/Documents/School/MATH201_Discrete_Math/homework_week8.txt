1. Prove that the sum of two even integers is even.
Let a = 2m and b = 2n for integers m, n.
a + b = 2m + 2n = 2(m + n)
Since (m + n) is an integer, a + b is even. QED.

2. Use induction to prove that 1 + 2 + 3 + ... + n = n(n+1)/2

Base case: n = 1
LHS = 1
RHS = 1(2)/2 = 1 ✓

Inductive step: Assume true for n = k, i.e., 1+2+...+k = k(k+1)/2
Show true for n = k+1:
1+2+...+k+(k+1) = k(k+1)/2 + (k+1)
= (k+1)[k/2 + 1]
= (k+1)(k+2)/2
= (k+1)((k+1)+1)/2 ✓
